# Patient Routes

This route group contains all patient-specific pages and functionality.

## Pages to implement (Phase 5-6):
- `/dashboard` - Patient dashboard with emergency button and categories
- `/emergency` - Emergency view with critical medical information
- `/medications` - Medications management
- `/allergies` - Allergies management
- `/exams` - Medical exams management
- `/diseases` - Diseases/conditions management
- `/consultations` - Medical consultations management

## Features:
- Emergency access with PIN display
- Medical record CRUD operations
- Multi-input entry system (text, voice, photo)
- AI-powered data extraction
- PDF export and QR code generation
