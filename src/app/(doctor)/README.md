# Doctor Routes

This route group contains all doctor-specific pages and functionality.

## Pages to implement (Phase 7):
- `/dashboard` - Doctor dashboard with patient search
- `/patient/[id]` - Patient profile access
- `/patient/[id]/medications` - Patient medications (doctor view)
- `/patient/[id]/allergies` - Patient allergies (doctor view)
- `/patient/[id]/exams` - Patient exams (doctor view)
- `/patient/[id]/diseases` - Patient diseases (doctor view)
- `/patient/[id]/consultations` - Patient consultations (doctor view)

## Features:
- Patient search by CPF + PIN
- Access to patient medical records
- Add entries to patient records
- View patient emergency information
- Track doctor-created entries
